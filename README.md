# Wire workspace

Thin-pipe **grammar**: illocutions, codes, expand/heal. Human text compose and languages live in the sibling **`@local-hosting/compose`** repo (`ai → compose → wire`).

| Path | Package |
|------|---------|
| [`packages/wire`](./packages/wire) | `@local-hosting/wire` |
| [`apps/demo`](./apps/demo) | Browser demo (depends on compose + wire) |

## What wire is for

Pack tiny on-air frames (tip fingerprint + codes) for LoRa / BT / thin pipes. Same codes for kitchen-table life and disaster response — compose turns natural language into those frames.

Everyday / resilience **message examples** and multilingual labels: see [`../compose/README.md`](../compose/README.md).

## Commands

From the **local-hosting** root (workspaces):

```bash
yarn install
yarn build && yarn test
yarn demo
```
